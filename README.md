# 42tui

> ⚠️ **Early Development — Not Stable Yet**

## Project Status

**42tui is currently in a very early stage of development.**

The application should **not be considered stable or secure** at this point. You may encounter bugs, incomplete features, unexpected behavior, or installation issues.

The project is still evolving rapidly, so configuration, scripts, naming, and functionality may change without notice.

## Project Name

The project was recently renamed from **42cli** to **42tui**.

However, because the project is still in a very early development stage, the rename has **not yet been reflected everywhere**.

You may therefore still find references to `42cli` in:

- Source code
- Configuration files
- Scripts
- Documentation
- Installation messages
- Other parts of the project

This is expected for now and will be cleaned up as development progresses.

## Requirements

The main requirements for installing and running 42tui are:

- [Podman](https://podman.io/)
- [Go (Golang)](https://go.dev/)

Make sure both are installed and available in your system before proceeding.
